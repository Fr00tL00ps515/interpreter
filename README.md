Project
Prerequisites
To run this project, your device needs to support:

Java — used to build and run the backend
Node.js — used to execute JavaScript code

Make sure both are installed and available in your system's PATH before proceeding.

How to Run
Option 1: Using an IDE
Open the project in your preferred IDE (e.g. IntelliJ IDEA, VS Code) and use the built-in run configuration to build and launch the application.
Option 2: Using the Command Line
From the project root directory, run the following commands:
./gradlew build
./gradlew run

Usage
Once the program is running, it reads your input line by line directly from the terminal. Type your commands one at a time and press Enter after each one.
To signal the end of your input, enter a newline character (\n) as the last line.
